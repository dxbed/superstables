Why a router

The rails are built. Nobody connects them.

Coinbase routes to Base. Stripe routes to Tempo. Every directory lists services but settles nothing. An agent that wants to pay for data today has to learn four protocols, hold three stablecoins and bet on who wins. Superstables sits between every agent and every rail — and is neutral in a way no incumbent can be.

Detect

Hit any URL. The router reads the 402 challenge, the MPP session, or the AP2 mandate and figures out what the endpoint speaks, on which chain, in which stablecoin.

Route

Every live facilitator is quoted on fee, latency and health. The cheapest compliant path wins; if a rail drops mid-payment, the router fails over instead of failing.

Settle, never hold

Payments are signed from the agent's own smart-contract wallet. Superstables never holds funds — the policy and the ledger are the product, not custody.

The whole API

Two lines. Every rail.

TypeScript and Python SDKs, a CLI for humans, and an MCP server so Claude, Codex and Gemini agents pick it up without a wrapper.

Pay

superstables/pay
import { pay } from "superstables";

const res = await pay.route(
  "https://api.example.com/v1/prices",
  { max: "0.05 USDC" }
);

// → protocol: x402 · chain: solana · fee: $0.0004
// → receipt: 0x3f9a…e2c1 · spent: 0.0104 USDC
res.body  // the data you paid for
Protocol, chain, stablecoin and facilitator are chosen at call time. Your code never changes when a rail does.

Principal control plane

Let an agent hold money without losing sleep.

A prompt injection shouldn't be able to drain a wallet. Policies are enforced on-chain by the agent's smart-contract wallet — not in application code the model can talk its way around.

superstables.policy.yamlenforced on-chain

approve_above: 10.00 USDC
stables: [USDC, EURC]
kill_switch: on
caps

Per-call, session and daily limits

Set once by the principal; the wallet refuses anything above them, whatever the agent was told.

lists

Allow and deny by domain

Pay only the services you've approved. Unknown counterparties never get a signature.

approvals

Human-in-the-loop above a threshold

Large spends pause for a tap on your phone. Small ones flow at machine speed.

kill switch

Stop everything, instantly

One click revokes the agent's signing rights across every rail and chain at once. Anomaly alerts tell you when to use it.
